# Edit the wyre.ai Site

Make a content change to wyre.ai from a plain-language description.

## Arguments

- `change` (optional) — what to change, e.g. "homepage headline to 'AI that ships'". If omitted, ask what they'd like to change.

## Steps

1. Follow the **WYRE Site Editing** skill end-to-end for the requested change.
2. Hand off to **WYRE Site Preview** so the user gets their preview link without asking.
